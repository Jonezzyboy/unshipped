# unshipped

Desktop app that shows which of your GitHub repos have commits waiting on a release, suggests the next semver bump, and cuts the release with generated notes.

Built with Tauri 2 (Rust backend, TypeScript frontend).

## Auth

The app reuses the [GitHub CLI](https://cli.github.com)'s login — it runs `gh auth token` and inherits exactly the access you have in the terminal, including org private repos. No OAuth app, no PAT, nothing stored by the app itself.

Requirements: `gh` installed and signed in (`gh auth login`).

## Run

```sh
npm install
npm run tauri dev
```

Build a distributable app with `npm run tauri build`.

## How it works

- **Repo list** — everything you own, collaborate on, or can access via org membership (archived repos are hidden). Sorted by most unshipped commits first.
- **Waiting count** — commits on the default branch since the latest release (GitHub compare API). Repos with no releases show total commit count.
- **Version suggestion** — conventional commits since the last release decide the bump: `BREAKING CHANGE` / `feat!:` → major, `feat:` → minor, otherwise patch.
- **Release notes** — generated by GitHub's release-notes API (same output as the "Generate release notes" button on github.com), editable before publishing.
- **Create release** — tags the default branch head and publishes the release.
